# 一括作成ツール 手順書（MLB CUP 2026 ビジョン用）

作成：2026-11-17 ／ 色は MLB 指定 #21BEC6（`make.py` の `RED`）

## 結論：ダブルクリックする順番
| 順 | ファイル | やること |
|---|---|---|
| 0 | `準備（最初に1回）.bat` | 部品を入れる（通信が必要。約200MB＋背景切り抜きモデル約180MB は初回の実行時に自動で入る） |
| 1 | `1_名簿を作る.bat` | 各チームの「選手登録フォーム.xlsx」から選手一覧を作る |
| 2 | `2_選手スライドを全員作る.bat` | 全員のスライドを作る（約200人で20分ほど） |
| 3 | `3_1人だけ作り直す.bat` | 写真を差し替えた人だけ作り直す（1人6秒ほど） |
| 4 | `4_入場・対戦・進行バナーを作る.bat` | 入場・対戦・進行を、一覧CSVから作る |

## 最初の準備
1. `準備（最初に1回）.bat` をダブルクリック。
2. `settings.example.json` を `input\settings.json` という名前でコピーし、`data_root` を、リーグ別フォルダが入っている場所に書き換える（例：`MLB CUP` フォルダ）。
3. 各チームのフォルダに「選手登録フォーム.xlsx」「決勝進出_プロフィール*.xlsx」と写真があること。
4. ロゴは、公式ロゴ資料「MLB CUP 2026 PRIMARY MARKS」（ベクターPDF／zip）から作る。PyMuPDF が入った Python で：
   `python logo_from_primary_marks.py （資料のpdf か zip）`
   → `assets\logo\MLBCUP2026_horiz_white.png`（横長）と `MLBCUP2026_stack_white_vector.png`（2段）ができる。
   ※ 2026-11-17 に作成済み（承認サンプルから切り出した仮ロゴは `…_仮(承認見本から切り出し).png` として残してある）。

## 1. 名簿を作る → 確認する
- 出力：`input\roster.csv`（選手一覧）、`input\teams.csv`（チーム名・リーグ名）、`output\確認_選手データ.csv`
- **チーム名を直したいとき**は `input\teams.csv` の `display` を直す（次回から残る）。画面に出る名前はこの列。
- 打率・防御率のルール：
  - 「打率.429 3安打…」の型はそのまま読む。
  - 数字だけの欄は、欄の種類で決める（打者欄の `500` → .500、投手欄の `3,31` → 3.31）。**変換した分は確認リストに出る**。
  - 防御率は小数2桁に丸める（例 0.857 → 0.86）。
  - 「-」「―」・空欄は空欄のまま（記録なし。創作しない）。
  - ポジションが複数あるときは、先頭だけ表示（確認リストに出る）。
- Excel でフォームを開いたままだと読めない。閉じてから実行する。

## 2. 選手スライドを作る
- 出力：`output\選手\チーム名\背番号_名前.png`（1920×1080）
- 写真との紐付け（別人の写真を出さないことを最優先）：
  - **名前がまるごと一致**した写真を使う（空白の全角/半角・有無は無視）。
  - 名字だけなど**部分一致**のときは、写真の背番号と名簿の背番号が合うときだけ使う。
  - 監督・コーチ・会長・集合写真は、名前の照合に使わない。
- 古いスライドは消さず、作り直す前に `output\選手\_退避\日時\` へ移す（古い画像が残って混ざらないように）。
- 同じチームで背番号が重なっていると、止まる（フォームを直してから、名簿づくりをやり直す）。
- 紐付けだけ確かめたいときは `python bulk_players.py --dry`（結果は `output\確認_紐付け.csv`。本番の確認リストは書き換えない）。
- **使わずに止める（作成せず）もの**は `output\確認_選手スライド.csv` に出る：
  - 写真が見つからない
  - 写真が複数ある／同じ写真が2人に当たった
  - 名前が合わず、背番号だけ（または似た名前だけ）合う「候補」…別人の写真を出さないため、目で確かめるまで使わない
- 候補が合っていると確かめたら、`input\photo_overrides.csv` に1行足す（なければ作る）。見出しは `team,no,file`。確認リストの「内容」欄に書き方が出ている。
  例：`○○ボーイズ,66,選手・指導者写真\66 山田太郎.JPG`
  足したあと、`3_1人だけ作り直す.bat` でその人を作る。
- `output\選手\要確認\` に分けるもの（目で確かめるまで使わない）：
  - 顔が見つからず位置が推測
  - 名前は合うが背番号が違う／同じ名前を含む写真が他にもある
- ふつうのフォルダに出すが、確認リストで目で確かめるもの：
  - 写真が短くて拡大した（1.25倍以上は特に）、下まで届かない
  - 胴の幅が狭い（目安2.0未満）＝白い壁に白いシャツで切り抜きが欠けた、またはアップ写真
  - 顔が複数見つかった（手前に別の人が写っていないか）
  - ※これらの基準は「目で見る目安」であり、問題なしの保証ではありません。
- コーチ・監督・集合写真は使われない。「使われなかった写真」として一覧に出る。

## 3. 1人だけ作り直す（当日の差し替え）
1. 新しい写真を、そのチームの写真フォルダに入れる（名前は「背番号 名前.JPG」がおすすめ）。古い写真は別の場所へ移す。
2. `3_1人だけ作り直す.bat` → チーム名の一部（例：稲沢）と背番号を入力（全角でもよい）。チームが複数に当たる、その背番号の選手がいない、のときは止まる。
3. 確認リストは、その人の行だけ入れ替わる。

## 4. 入場・対戦・進行
- `4_…bat` を**最初に押すと、`input\` にひな形ができて止まる**（仮の中身のまま画像は作らない）。CSVを直してから、もう一度押す。
  - `entrance.csv`（入場順）：入場順は引き継ぎ書の式次第どおりに仮で当てはめたもの。**チームとの対応は要確認**（公式プログラムに入場順の記載は無い）。
  - `matches.csv`（対戦）：公式プログラムのトーナメント表どおり、11/22 の**全4ブロック12試合**（各ブロック 1-2／2-3／3-1、左が先攻）。`venue` 列が画面右下の会場名。**会場の英語表記は仮**（KUSATSU／AI AI FUSHIMI MOMOYAMA／MORIYAMA／SHIGA KIBOGAOKA）。11/23 の準決勝・決勝は、チームが決まったら行を足す。
  - `program.csv`（進行）：式次第の8項目。英語名は空欄（空なら英語行は出ない）。**番号は画面に出さない**（並び順とファイル名にだけ使う）。
- 対戦バナーは**決定版**（名前を大きく、外側をセーフマージン120pxに、副題は左右に寄せる）。
- リーグ名は公式どおり5種類（リトルリーグ／ヤングリーグ／ポニーリーグ／ボーイズリーグ／フレッシュリーグ）。`teams.csv` の `league` 列。
- ロゴバナー（横長 32:9／16:9、2段 16:9）も、このBATで `output\ロゴ\` に出る。

## うまくいかないとき
- 「止めました」と出たら、その文のとおりに直す（黙って進まない作りにしてある）。
- 10人続けて失敗すると自動で止まる。
- 顔検出モデルは日本語を含む場所から直接読めないため、プログラム側でメモリ経由にしてある（`place.py`）。
