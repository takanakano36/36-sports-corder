# サッカー中継用スポーツコーダー 取扱説明書

本アプリケーションは、サッカーのライブ配信でスコア、タイマー、PK状況、選手紹介テロップなどをOBS等の配信ソフトに合成できる、スタンドアロン型のスポーツコーダーシステムです。

サーバーやデータベース等の環境構築は一切不要で、HTMLファイルをブラウザで開くだけで動作します。

## 🎨 チーム情報設定・カラー・ロゴ・表示モード

### 1. 表示モードの切り替え
ダッシュボードの「**表示モード**」セレクトボックスから、配信画面の表示形式を切り替えられます：
* **小得点** (画面左上): 添付画像のデザインを元にしたメタルプレートのミニスコアボード。上に細くチームカラーのラインが走り、下に時間が吊り下がります。
* **大得点** (画面下部): 各チームの英語表記（アルファベット名）とロゴ画像を含めた、ハーフタイムや結果表示に適した大型のスコアボード。
* **対戦 (VS)** (画面中央): 試合開始前や紹介時に使用する大型の対戦カード。上部に入力した大会名が表示され、中央に光る「VS」が配置されます。
* **非表示**: すべてのオーバーレイを非表示にします。

### 2. チームカラーの設定
* 各チームの「**カラー**」ピッカーをクリックし、自由なカラーを選択できます。
* 設定したカラーは、小得点の上部カラーラインや、オーバーレイ各部のテーマカラーとしてリアルタイムに反映されます。

### 3. チームロゴ画像の読み込み
* **ローカルファイルから選択**: 「ファイル選択」ボタンからローカルの画像ファイル（PNG/JPEG等）を選択します。プログラムが内部で **Base64データURLに自動変換して転送** するため、ローカルでダブルクリック起動しただけの環境でも画像を同期表示できます。
* **URLを入力**: ネット上にある画像ファイルの直リンクURLを直接テキスト入力して設定することも可能です。

## 📊 Googleスプレッドシート連携（選手一覧）

スプレッドシートで管理している選手名簿を、ボタン一つでダッシュボードに一括読み込みできます。

### 1. スプレッドシートの準備
スプレッドシートのシート内に、以下のカラム順でデータを作成します。（※1行目はヘッダー行としてスキップされます）

| A列 (背番号) | B列 (ポジション) | C列 (名前) | D列 (学年/紹介メモ) | E列 (一言コメント) | F列 (チーム) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 10 | MF | 香川 真司 | 3年 | 創造性溢れる司令塔。ファンタジスタ。 | HOME |
| 9 | FW | ハーランド | 2年 | ゴールを奪うために生まれた怪物。 | AWAY |

* **チーム列 (F列)**: `HOME` または `AWAY` を指定することで、ダッシュボード上のタブに自動的に振り分けられます。空欄の場合は `HOME` として扱われます。
* **選手写真について**: この一括読み込み機能では画像URLは読み込まれず、写真は常にデフォルトのサッカーボールアイコンで表示されます。

### 2. ウェブに公開する手順
1. Googleスプレッドシートのメニューから「**ファイル**」＞「**共有**」＞「**ウェブに公開**」を選択します。
2. 公開範囲を「**シート全体**」または「**該当のワークシート**」にし、形式を「**カンマ区切り値 (.csv)**」に選択して「公開」をクリックします。
3. 生成された公開用の `https://docs.google.com/spreadsheets/d/.../pub?output=csv` のようなURLをコピーします。

### 3. ダッシュボードでの読み込み
1. コピーしたURLをダッシュボードの「**Google スプレッドシート連携**」入力欄に貼り付けます。
2. 「**読み込み**」ボタンを押すと、選手一覧テーブルが更新されます。
3. リスト内の「**テロップ表示**」をクリックすると、指定した秒数だけ配信画面下部に美しいアニメーション付きで選手カードが表示されます。

> [!TIP]
> テスト用として、「**デモ選手(HOME)**」「**デモ選手(AWAY)**」ボタンを用意しています。スプレッドシートを用意する前に、こちらをクリックするだけでリッチな選手紹介テロップをすぐに実演・確認できます。

## 🖼️ Googleスライド連携（ワンショットテロップ画像）

スライドで自由にデザインした「選手紹介スライド」「スタッツ画像」「スポンサー枠」などの画像を、配信画面上にワンショット（フェードイン・フェードアウト）で表示できます。

1. **Googleスライドでのデザイン**:
   - スライドのページ設定を `16:9` にしてテロップを作成します。背景を透過させたい場合は、スライドの背景色を「透明」にするか、クロマキー用の単色（緑など）にします。
2. **ウェブに公開**:
   - Googleスライドのメニュー「**ファイル**」＞「**共有**」＞「**ウェブに公開**」を選択し、リンクを発行します。
3. **画像URLの取得と変換**:
   - 発行したリンク、または編集用URL（`https://docs.google.com/presentation/d/[スライドID]/edit#slide=id.[スライドページID]`）をダッシュボードの「**Googleスライド画像テロップ**」の入力欄に入力します。
   - ※ダッシュボードのプログラムが、スライドの個別ページをPNG画像としてエクスポートするURLに内部で自動変換します。
4. **送信**:
   - 表示時間を設定し、「**表示送信**」をクリックすると配信画面全体にフェードインでスライド画像が表示されます。

## 🥅 PK戦コントロール

試合がPK戦に突入した際の専用トラッカーです。

1. ダッシュボードの「**PKモード**」のトグルをONにするか、ピリオド選択で「**PK戦(PK)**」を選択します。
2. 配信画面の上部スコアボードの下から、PK用のボールゲージがスライドイン表示されます。
3. ホームの1人目からスタートし、ダッシュボードの「**成功 (○)**」または「**失敗 (✕)**」をクリックするだけで、結果が同期され、自動的に次のキッカー（交互）にカーソルが進みます。
4. 5人目で決着がつかない場合は、6人目以降（サドンデス）のインジケーターが自動的に拡張されます（最大10本まで追従）。
5. 誤入力した場合は「**１つ戻す**」で前の判定をキャンセルでき、「**PKクリア**」で全結果を即時リセットできます。

## 🎥 OBS Studio への設定手順（配信ソフト）

1. OBSの「**ソース**」パネルの下部にある「**+**」ボタンを押し、「**ブラウザ**」を選択します。
2. 「新規作成」で名前（例：スポーツコーダー）を付けます。
3. 設定プロパティで以下のように入力・設定します。
   * **ローカルファイル**: チェックを入れる。
   * **参照**: 本フォルダ内の `soccer_overlay.html` を選択する。
   * **幅**: `1920`
   * **高さ**: `1080`
   * **カスタムCSS**: （空欄のままで問題ありません。デフォルトの `body { background-color: rgba(0, 0, 0, 0); margin: 0px; auto; overflow: hidden; }` のままでも機能します）
4. 透過の設定について：
   * **方法A（完全透過）**: ダッシュボードのクロマキー背景色で「**透過 (本番用)**」を選択します。OBS側の「ブラウザソース」はデフォルトで背景透過で取り込まれるため、これだけで余計な背景が完全に抜け、スコアボードやテロップだけがゲーム映像の上に綺麗に重なります（最もおすすめの設定です）。
   * **方法B（クロマキー合成）**: ダッシュボードで「**グリーン**」等を選択している場合、OBSでブラウザソースを右クリック ＞「**フィルタ**」を選択し、「エフェクトフィルタ」の「+」から「**クロマキー**」を追加します。「色キー色」で緑を選択して微調整することで、背景の緑が透過されます。
