# スタジアムビジョン得点板システム

スタジアムの大型ビジョンに出すアメフトの得点板です。
管理画面で操作した内容が、表示画面（1920×1080）にすぐ反映されます。

---

## 0. かんたん手順（まずはここだけ）

### はじめてのPCで使うとき（1回だけ）
1. この `STADIUMVISION得点板システム` フォルダを、PCの好きな場所にまるごとコピーします。
2. PCに **Node.js** が入っていなければ、https://nodejs.org/ja から「LTS」版を入れます。
3. フォルダの中の **「デスクトップにショートカットを作る.bat」** をダブルクリックします。
   → デスクトップに **「得点板 管理画面」「得点板 HDMI出力」** の2つのアイコンができます。

### 試合のたびに
| やりたいこと | デスクトップのアイコン |
|---|---|
| 得点を操作する | **「得点板 管理画面」** をダブルクリック → 管理画面が開きます |
| スイッチャーへHDMIで直接出す | **「得点板 HDMI出力」** をダブルクリック → HDMIの画面に全画面で出ます |
| OBSに取り込む | 管理画面右上の **「⠿ OBSへドラッグ」** をOBSへドラッグ（最初の1回だけ） |

- 黒い画面（サーバー）は、試合が終わるまで閉じないでください。
- 管理画面を閉じてしまったら、もう一度「得点板 管理画面」をダブルクリックすれば開き直せます。
- 試合の状態は自動で保存されます。PCが落ちても、アイコンから起動し直せば続きから再開できます。

## 1. 起動のしかた（くわしく）

1. 「得点板 管理画面」（＝このフォルダの **「サーバー起動.bat」**）をダブルクリックします。
   - 準備ができると、**管理画面がいつものブラウザで自動的に開きます**（アドレスの入力は不要です）。
   - 黒い画面が開いたままになっていれば起動中です。**試合が終わるまで閉じないでください。**
   - Node.js が入っていないPCでは、その旨が表示されて止まります。
2. 管理画面を閉じてしまったときは、もう一度ダブルクリックしてください。
   - サーバーはそのまま動き続け、管理画面だけがもう一度開きます（後から開いた黒い画面は閉じて大丈夫です）。

> 試合の状態（得点・Q・TOなど）は、操作するたびに `data/state.json` に自動で保存されます。

## 2. 映像の出し方

### A. PCのHDMIからスイッチャーへ直接入れる場合（OBSを使わない）

1. PCのHDMI端子とスイッチャーの入力をつなぎます。
2. Windows の「設定」→「ディスプレイ」で、
   - 表示方法を **「表示画面を拡張する」** にします。
   - HDMI側の画面の解像度を **1920×1080** にします。
3. デスクトップの **「得点板 HDMI出力」**（＝このフォルダの「HDMI出力.bat」）をダブルクリックします。
   - サーバーが動いていなければ、自動で起動します。
   - HDMIの画面（主画面以外の画面）を自動で探し、得点板を**全画面**で表示します。
   - 主画面以外の画面が複数あるときは、番号で選ぶ画面が出ます。
   - HDMIの画面が見つからないときは、確認のしかたが表示されます。
4. 表示を終わるときは、その画面をクリックして **Alt＋F4** を押します。
   - もう一度「得点板 HDMI出力」をダブルクリックすると、開き直せます（前の表示は自動で閉じます）。

> Microsoft Edge の「キオスクモード」（案内板用の表示方式）で開くため、メニューやアドレス欄は出ません。
> 表示中は画面がスリープしないようにしています。マウスカーソルも自動で消えます。
> HDMIの画面が16:9でない場合は、上下または左右に黒い余白が付きます（得点板の形は崩れません）。

### B. OBS に取り込む場合

アドレスを覚えておく必要はありません。管理画面の右上「**OBSに入れる**」から入れられます。
OBSはシーンにソースを保存するので、この作業は**最初の1回だけ**です。

- **方法1（いちばん簡単）**：管理画面の「**⠿ OBSへドラッグ**」ボタンを、OBSの画面（プレビューの上）へドラッグ＆ドロップします。
- **方法2**：管理画面の「**アドレスをコピー**」を押し、OBSで「ソース」→「＋」→「ブラウザ」を追加して、URL欄に貼り付けます（幅 `1920`・高さ `1080`、「ローカルファイル」のチェックは外す）。

最後に、OBS の出力（プログラム出力・プロジェクター出力など）をビジョンへ送ります。

## 3. 管理画面でできること

| 項目 | 操作 |
|---|---|
| クォーター | 1Q〜4Q・OT を切り替え（OTの行はOTにした時だけ表示） |
| 得点 | TD +6 / FG +3 / +2 / +1 / −1（いまのQに加算。合計は自動計算） |
| 演出動画 | TD（+6）を押すとそのチームのTD動画、FG（+3）を押すとFG動画が全画面で流れ、終わると得点板に戻ります（戻ったときには得点が増えています）。「TD・FGで演出動画を流す」のチェックを外すと流れません。「動画だけ流す」「■ 止める」ボタンもあります |
| 得点の修正 | 「Qごとの得点」の表で数字を直接書き換え |
| タイムアウト | −／＋（各チーム0〜3）、「両チームを3に戻す」 |
| 攻撃権 | 左／なし／右（チーム名の横に金色のボールが付きます） |
| ダウン | 1st〜4th、残り距離（数字・GOAL・INCHES）、「1st & 10 にする」 |
| BALL ON | 数字入力、−5／−1／＋1／＋5 |
| 表示の切り替え | ダウン、BALL ON をそれぞれ表示・非表示（両方消すと下の帯ごと消えます） |
| 対戦バナー | 上部のタブ「対戦バナー」で、試合の情報（大会名・日付・会場・リーグロゴ）と対戦（キックオフ・左右のチーム・ニックネーム・ロゴの大きさなど）を登録。「対戦バナーを出す」で ①②①②… と決めた秒数ごとに切り替えて表示、「得点板に戻る」で得点板へ。フッター（日付・会場・キックオフ）なし版も選べる。「得点板に入れる」で、その対戦のチームを得点板に反映 |
| 大会名・チーム名 | 文字を入力（長いチーム名は、文字の高さはそのままで横幅だけ自動で縮みます） |
| ロゴ | 一覧から選択、または「画像を追加」（PNG・JPEG・SVG・WEBP、5MBまで） |
| チームカラー | カラーチャート、色番号（例：#7b1936）、ロゴから取った色の候補 |
| TD演出動画 | チームごとに一覧から選択、または「動画を追加」でエクスプローラーから登録（MP4・WEBM・M4V、500MBまで）。FG演出動画は中央の「演出動画」欄で両チーム共通に1つ登録 |
| ロゴの縁取り | 色（白・黒・金・チームカラー・自由な色）と太さ（0〜12、0で縁取りなし）をチームごとに設定。白いロゴは黒やチームカラーの縁取りにすると見やすくなります |
| 左右を入れ替え | 左右のチームを、得点・TOごと入れ替え |
| 試合をリセット | 得点・Q・TO・攻撃権・ダウンを試合開始前に戻す（チーム設定はそのまま） |

おかしな値（TOを4にする、BALL ONを51にする など）は反映されず、画面上部に理由が表示されます。

## 4. Stream Deck などから操作する場合

次のアドレスを開くと操作できます（Stream Deck の「Webサイト」アクション等で使用）。

```
http://localhost:3006/api/control?action=操作名&team=チーム&val=値
```

| 操作名 | 例 | 内容 |
|---|---|---|
| addScore | `action=addScore&team=home&val=6` | いまのQに得点を加算（home=左、away=右） |
| setQ | `action=setQ&team=away&q=2&val=7` | 指定したQの得点を書き換え |
| setPeriod | `action=setPeriod&val=3` | クォーター（1〜4、5=OT） |
| nextPeriod | `action=nextPeriod` | 次のクォーターへ |
| adjustTO | `action=adjustTO&team=home&val=-1` | タイムアウト増減 |
| resetTO | `action=resetTO` | 両チームのTOを3に戻す |
| setPossession | `action=setPossession&val=away` | 攻撃権（home / away / none） |
| setDown | `action=setDown&val=2` | ダウン（1〜4） |
| setToGo | `action=setToGo&val=GOAL` | 残り距離（1〜99 / GOAL / INCHES） |
| setBallOn | `action=setBallOn&val=35` | BALL ON（1〜50） |
| toggleDown | `action=toggleDown` | ダウンの表示・非表示 |
| toggleBall | `action=toggleBall` | BALL ON の表示・非表示 |
| playTD | `action=playTD&team=home` | 得点は変えずに、そのチームのTD演出動画だけ流す |
| playFG | `action=playFG` | 得点は変えずに、FG演出動画だけ流す |
| stopEffect | `action=stopEffect` | 流れている演出動画を止めて得点板に戻す |
| toggleEffects | `action=toggleEffects` | TD・FGで演出動画を流すかのオン・オフ |
| showBanner | `action=showBanner` | 対戦バナーを出す（①から） |
| hideBanner | `action=hideBanner` | 得点板に戻る |
| toggleBannerFooter | `action=toggleBannerFooter` | 対戦バナーのフッターのあり／なし |

※ `addScore` で `val=6`（TD）・`val=3`（FG）を送ったときも、演出がオンなら演出動画が流れます。

---

## 5. 注意

- **インターネットなしで動きます。** 文字の書体（Oswald・Noto Sans JP）は `fonts/` フォルダに入っています。どちらも無料で商用利用・組み込みができる「SIL Open Font License 1.1」の書体です（原文：`fonts/OFL_Oswald.txt`、`fonts/OFL_NotoSansJP.txt`）。
- ロゴ画像（`logos/` フォルダ）、演出動画（`videos/` フォルダ）、試合の保存データ（`data/` フォルダ）は、Gitの管理から外しています（大学のロゴを誤って公開しないため・動画は容量が大きいため）。別のPCで使うときは、フォルダごとコピーしてください。
- 演出動画は、表示画面が画面に見えている状態で再生されます。うまく再生できなかったときは、管理画面の上部に赤い文字で知らせます（ビジョンには何も出ません）。
- ポート番号は `3006` です（他の競技システム 3001〜3005 と同時に起動できます）。
