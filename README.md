# AAC Sports Corder (スポーツコーダー統合ゲートウェイ)

ALL ARTS CREATE.Inc. が提供する各種競技スポーツコーダー（スコア＆テロップ送出システム）を一元管理し、ワンクリックで別ウィンドウ起動できるゲートサイトです。

---

## 🌟 主な機能と特徴

1. **ワンクリック別ウィンドウ起動**
   - 各競技カードの「ダッシュボードを起動」ボタンをクリックすると、操作に最適な別ウィンドウサイズで即座に立ち上がります。
   - 「テロップ送出窓」ボタンから、1080p（FHD）クリーン出力用のオーバーレイ画面を直接開くことも可能です。

2. **初期搭載 5競技**
   - ⚽ **サッカー (SOCCER)**: 得点、前後半タイマー、アディショナルタイム、スタメン/交代/カード管理
   - 🏀 **バスケットボール (BASKETBALL)**: Q別スコア、24s/14sショットクロック、ファウル、タイムアウト、デュアル出力
   - 🏐 **バレーボール (VOLLEYBALL)**: 5セット制スコア、サーブ権、タイムアウト、ローテーション
   - ⚾ **野球 (BASEBALL)**: BSOカウント、ランナー塁状況、イニング表裏、打順/守備位置
   - 🏈 **アメリカンフットボール (AMERICAN FOOTBALL)**: ダウン＆ディスタンス、ボールオン、クォーター時間

3. **柔軟な競技追加・編集機能**
   - ヘッダー右上の「＋ 競技を追加」またはグリッド末尾の「＋ 競技を追加する」カードから、テニス、ハンドボール、ラグビー、卓球、バドミントンなどの新競技を自由に追加・登録できます。
   - 各カードの「設定」ボタンから、起動先URLやファイルパスを現場の環境に合わせて変更・保存可能（ブラウザの LocalStorage に自動保存されます）。

4. **ALL ARTS CREATE.Inc. 公式ブランディング**
   - ヘッダーおよびフッターに公式ロゴ・表記「Presented by ALL ARTS CREATE.Inc.」と公式HP（[all-arts-create.com](https://all-arts-create.com/)）へのリンクを配置。

---

## 🚀 使い方

- `index.html` をブラウザ（Google Chrome, Edge 推奨）で開くだけで、完全オフライン環境でも動作します。
- ※別ウィンドウ起動時にブラウザのポップアップブロックが表示された場合は、アドレスバー右側等から「ポップアップを許可」してください。
