## 1. 決まったこと（ここまでの合意）

| 項目 | 決定 |
|---|---|
| デザインの方向 | MLB中継の雰囲気。昨年のデザインは参照しない。AIっぽい・ダサいのはNG |
| 色 | **紺＋赤の2色だけ**（ネオンカラーなし）。例外は対戦バナーの「VS」だけ黄色 |
| 画面サイズ | 基本は **16:9（1920×1080）**。32:9（3840×1080）はロゴと式次第だけ |
| 選手スライド | **A案（中継風）**で確定。写真の下端は**水平カット＋細い線** |
| 対戦バナー | **紺一色＋赤ライン**の版で確定（左右に色分けする版は不採用） |
| 進行・入場の大きな数字 | 両方残す（進行＝式次第の番号、入場＝入場順） |
| 記録の表記 | 打率は小数点以下3桁「.400」。防御率は小数2桁。**記録なし・不明は空欄**。創作は禁止 |
| チーム名 | 各チームの「正式名称」欄のもの。長音・誤字は修正。「Unites Niigata」はこの表記 |
| 選手スライドの項目 | 学年・ポジション・打率・防御率・投・打 |

## 3. 選手スライド（A案）の寸法　※ `slideA.py` / `place.py`

**写真（自動配置）**
- 背景を切り抜いて（rembg `isnet-general-use`）、顔を検出し（OpenCV YuNet）、**全員の顔の大きさと位置を揃える**
  - 顔の幅 **218px**、顔の中心 **x500 / y457**
- 写真の下端は **y952 で水平カット**（右の「0.00 左 左」の数字の下ラインと同じ高さ）
- 細い線：y952、太さ3px、白（不透明度約80%）、x120 から赤ラインの手前まで
- 写真が短くて y952 に届かない人は、届くところまで**自動で少し拡大**（拡大した人は一覧に出す）
- 写真の後ろに薄い影（ぼかし40px）

**写真の自動処理で対応済みの問題**（他チームで試して見つかったもの）
- スマホ写真が横倒し → 回転情報(EXIF)を反映
- 隣の子が写り込む → 顔とつながっている本人の部分だけ残す
- メガネ・横長写真で顔を読み違える → 顔検出を YuNet に変更して解決
- 白い壁に白いシャツ → 背景の抜けが甘くなる。**目視確認の対象**にする

**レイアウト**
- 赤ライン：多角形 (905,0)-(965,0)-(765,1080)-(705,1080)
- 後ろの大きな背番号：輪郭だけ、Oswald 1000px、線6px、白・不透明度約37%、中心 x310・下端 y952
- 右側の文字列は x1060 から
  - 1行目（y300）：赤「#背番号」Oswald 64 ＋ 縦線 ＋ チーム名（英字は Oswald 40、**日本語は和文 Bold 38**）
  - 名前（y470）：和文 Heavy 150px。右端 x1830 に入らなければ**自動で縮小**
  - ふりがな（y535）：和文 Medium 34、字間広め、グレー
  - 区切り線：y580〜583、x1060〜1830
  - 成績：3列×2段（GRADE学年 / POS / AVG打率、ERA防御率 / THROWS投 / BATS打）
    - 見出し：赤の英字 Oswald 26 ＋ グレーの和文 22
    - 値：数字は Oswald 110、和文は Heavy 84。**セル幅に入らなければ自動で縮小**。空欄は何も出さない
- ロゴ：横長・白、高さ46px、右上（右端 x1830・y92）

## 4. バナー類の寸法　※ `banners.py`

**共通フッター**：線 y930（x120〜1800、白・薄め）／左に横長ロゴ 高さ40（x120, y960）／右に日付・会場 Oswald 30。赤ラインはフッターの線で止める。

| バナー | 内容 |
|---|---|
| 入場（16:9） | 左に赤「TEAM ENTRANCE」＋短い線、チーム名 Heavy 180（自動縮小）、下に連盟名。右に**入場順の大きな数字**（輪郭だけ）。フッター右「11.21 SAT OPENING CEREMONY」 |
| 対戦（16:9）**確定版** | 上にヘッダー帯（高さ96、濃紺）に「Cブロック　第一試合」。中央から台形のタブを下げ、赤小文字「PLAY BALL」＋白「11.22 SUN 9:00」。赤ライン1本（タブの下〜フッター線、斜め）。**左チームは左上（右揃え）、右チームは右下（左揃え）**、赤ラインに沿わせる。2チームの文字サイズは揃える（長い方に合わせて縮小）。名前の下に「— 連盟名 —」。VS は黄色の斜体で赤ラインの上。フッター右は会場名のみ |
| 進行（16:9） | 左に赤ライン、後ろに**式次第の番号**（輪郭だけ）。赤「OPENING CEREMONY」＋線、項目名 Heavy 210（自動縮小）、下に英語。例：07 選手宣誓 / PLAYERS' OATH |
| ロゴ・横長（32:9 と 16:9） | 紺版：中央にロゴ（幅 32:9は50%、16:9は62%）、左右に「／」向きの赤ライン（ロゴにかからない位置）。黒版：黒にロゴだけ |
| ロゴ・2段（16:9） | 紺版・黒版。ロゴ幅1180px。ロゴは**ベクターから作った** `MLBCUP2026_stack_white_vector.png` |

関数：`entrance(順番, チーム名, 連盟)`、`matchup2(ヘッダー, 日時, チーム1, 連盟1, チーム2, 連盟2, 会場, style='line')`、`program(番号, 和名, 英名, 見出し)`、`logo_banner(w, h, 'design'|'black')`、`stack_banner('design'|'black')`

## 7. 次の作業：選手スライドの一括作成ツール

ここで1枚ずつ作るより、PCで一括作成する方が使用量・速さとも圧倒的に有利（約210人で10〜20分、当日の差し替えは1人数秒）。

作るもの：
1. **写真と選手の紐付け**：背番号と名前（空白の全角/半角・有無を無視）の両方で照合。紐付かなかった写真・選手は一覧に出す。コーチ・監督・集合写真は除外
2. **HEIC対応**（pillow-heif）
3. **一括書き出し**：`output/チーム名/背番号_名前.png`
4. **確認リスト**（CSV）：顔が見つからない／写真が短くて拡大した／背景の抜けが甘そう／写真なし
5. **1人だけ作り直す**オプション（当日の差し替え用）
6. 入場・対戦・進行バナーも一覧（CSV）から一括で作れるように
7. ダブルクリックで準備・実行できる `.bat`（Windows）と手順書

必要なもの：Python 3、`pip install rembg[cpu] "opencv-python-headless<5" pillow pillow-heif numpy`、
顔検出モデル `models/yunet.onnx`（opencv_zoo の `face_detection_yunet_2023mar.onnx`）、rembg の初回モデル（約170MB、自動ダウンロード）
