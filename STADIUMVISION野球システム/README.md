# スタジアムビジョン野球システム（32:9 ／ フルHD 2画面）

野球場の大型ビジョン（3840×1080 ＝ フルHDを左右に2面）に、スライド・カメラ映像・選手紹介を出すシステムです。
アメフト用の「STADIUMVISION得点板システム」をもとに作っています。**音楽バー・HDMI出力・ショートカットの使い方は同じ**です。
得点板の機能はありません。

---

## 0. かんたん手順（まずはここだけ）

### はじめてのPCで使うとき（1回だけ）
1. この `STADIUMVISION野球システム` フォルダを、PCの好きな場所にまるごとコピーします。
2. PCに **Node.js** が入っていなければ、https://nodejs.org/ja から「LTS」版を入れます。
3. フォルダの中の **「デスクトップにショートカットを作る.bat」** をダブルクリックします。
   → デスクトップに **「野球ビジョン 管理画面」「野球ビジョン HDMI出力」** の2つのアイコンができます。

> Macの場合は、名前に「（Mac）」が付いたファイルを使います（手順は得点板システムのREADMEの「6. Macで使う場合」と同じです）。

### 本番のたびに
| やりたいこと | デスクトップのアイコン |
|---|---|
| 画面を操作する | **「野球ビジョン 管理画面」** をダブルクリック → 管理画面が開きます |
| ビジョンへHDMIで直接出す | **「野球ビジョン HDMI出力」** をダブルクリック → ビジョンの画面に全画面で出ます |
| OBSに取り込む | 管理画面右上の **「⠿ OBSへドラッグ」** をOBSへドラッグ（最初の1回だけ） |

- 黒い画面（サーバー）は、本番が終わるまで閉じないでください。
- 式次第・名簿・カメラの設定などは自動で保存されます（`data/state.json`）。PCが落ちても、アイコンから起動し直せば続きから再開できます。
- アメフトの得点板（3006番）と、この野球ビジョン（3007番）は、同じPCで同時に動かせます。

## 1. 映像の出し方

### A. PCのHDMIからビジョンへ直接（ケーブル1本）

1. PCのHDMI端子とビジョン（またはビジョンのコントローラー）をつなぎます。
2. Windows の「設定」→「ディスプレイ」で、
   - 表示方法を **「表示画面を拡張する」** にします。
   - ビジョン側の画面の解像度を **3840×1080** にします。
     一覧に無いときは、グラフィックの設定（NVIDIA コントロールパネル・Intel グラフィックス・AMD Software）の **「カスタム解像度」** で 3840×1080 を作ります。
3. デスクトップの **「野球ビジョン HDMI出力」** をダブルクリックします。ビジョンの画面に全体（3840×1080）を全画面で出します。
   - 画面が32:9になっていないときは、注意と直し方が表示されます（そのままだと上下に黒い余白が付いて小さく出ます）。

> 「野球ビジョン HDMI出力」は、つながっている画面の数で出し方を決めます。
> 1台 → 全体を出す ／ 2台 → 左の画面に左半分・右の画面に右半分（HDMI 2本でつなぐ現場用）／ 3台以上 → 番号で選ぶ

### A-2. HDMI→SDIコンバーター経由（SDI 1本・ビジョンに映るのは1920×1080の中の帯）

スタジアムのスイッチャーへ **SDI 1本** で入れ、スケーラーが **「横100%・上下トリミング」** でLED（例 488×160）に映す現場用です。
SDIは 1920×1080 までなので、3840×1080（32:9）はそのままでは送れません。この形で出すときは、**「32:9」から「SDI 1本」に切り替えて**ください。

1. 管理画面の **設定タブ →「出力の形」** で **「SDI 1本（1920×1080 の帯）」** を選びます。
2. 「LEDの大きさ」に **488 × 160** を入れて **「ここから帯を計算」** を押します。
   → 1920×630 の帯（上端 y=225、上下の中央）になります（1920×160÷488 ≒ 630）。
3. 素材タブの **「▦ テスト画面」** をビジョンに出し、**緑の枠がビジョンの四辺にぴったり合う**ように「帯の上端」「帯の高さ」を直します。
4. レイアウトは **「帯 一枚」「左右に2分割」（1枚 960×630。左に映像・右にスライドなど）「16:9 1枚（位置指定）」** から選びます。

PC・コンバーター（IMAGENICS CRO-H2SC）の設定：

| 場所 | 設定 |
|---|---|
| Windows のディスプレイ | 「表示画面を拡張する」、解像度 **1920×1080**、拡大縮小 100% |
| CRO-H2SC の EDID | **0（SDI OUT）** か **5（1920×1080）**（1 = 640×480 だと左右に黒みが出ます） |
| CRO-H2SC の OUT SDI | スイッチャーに合わせる（多くは **0 = 1080i 59.94**） |

- 「野球ビジョン HDMI出力」は、SDI 1本のときは**左右に分けず**、1つの画面に 1920×1080 で出します（ビジョン用の画面が2台以上あるときは番号で選びます）。
- 32:9 のときにビジョン用の画面が2台見つかると左右に分けて出すため、ノートPCの画面＋HDMI＋もう1台などの状態だと「左右が別々の画面に出る」ことがあります。

### B. OBSに取り込む場合

アドレスを覚える必要はありません。管理画面の右上「**OBSに入れる**」から入れます（得点板システムと同じ。最初の1回だけ）。

1. OBSの「設定」→「映像」で、**基本（キャンバス）解像度と出力解像度を 3840×1080** にします。
2. 管理画面の「**⠿ OBSへドラッグ**」をOBSのプレビューの上へドラッグ＆ドロップします（幅3840・高さ1080のブラウザソースになります）。
   - または「**アドレスをコピー**」を押し、OBSで「ソース」→「＋」→「ブラウザ」を追加してURL欄に貼り付けます（幅 `3840`・高さ `1080`、「ローカルファイル」のチェックは外す）。
3. OBSの出力（プロジェクター出力など）をビジョンへ送ります。

**OBSでカメラ（キャプチャーボード）を使うとき**（昨年と同じやり方）

「OBSに入れる」で入れた表示画面は、**カメラ1・カメラ2を入れた枠だけが透明**になります（カメラは開きません）。
OBSでキャプチャーボードを **ブラウザソースの下** に敷くと、その枠からカメラが見えます。

1. OBSの「ソース」→「＋」→「映像キャプチャデバイス」で、I-O DATAのキャプチャーボードを追加します。
2. ソースの並びで、**映像キャプチャデバイスを、ブラウザソース（野球ビジョン）より下** にします。
3. 映像キャプチャデバイスの位置・大きさを、カメラを出す枠に合わせます（ソースを右クリック →「変換」→「変換の編集」）。

| 管理画面でカメラを入れる枠 | 映像キャプチャデバイスの位置 | 大きさ |
|---|---|---|
| 16:9 左右2枚 の「左」 | 0, 0 | 1920 × 1080 |
| 16:9 左右2枚 の「右」 | 1920, 0 | 1920 × 1080 |
| 16:9 1枚（中央） | 960, 0 | 1920 × 1080 |
| 32:9 一枚（上下を切り取る） | 0, -540 | 3840 × 2160 |

- カメラを出さないときは、ブラウザソースがカメラを隠すので、映像キャプチャデバイスは出したままで大丈夫です。
- カメラの切り取り位置・拡大は、管理画面ではなく OBS の「変換」で決めます（管理画面のトリミングはカメラには効きません）。
- 枠の位置ごとに使い分けるときは、位置を変えた映像キャプチャデバイスを複数作り、目のマークで出し分けるか、OBSのシーンを分けます。
- BLACK を押すと、カメラも含めて黒くなります。
- ブラウザの中でカメラを開きたいとき（OBSを `--enable-media-stream` を付けて起動した場合など）は、OBSのURLから `camera=obs&` を消します。

### 共通
- 左右を取り違えていないかは、素材タブの **「▦ テスト画面」** を出すと確かめられます（左に「L」、右に「R」と出ます）。
- 「境目の線」にチェックを入れると、2画面の境目に赤い線を出せます（設置・調整用）。
- 表示を終わるときは、その画面をクリックして **Alt＋F4** を押します。
- カメラ（キャプチャーボード）の許可は、出力用の画面では自動で許可します（キオスクモードでは許可のボタンを押せないため）。

## 2. 画面の組み立てと送出

1. 右の **素材** タブでスライドやカメラを押す → プレビュー（PREVIEW）の **「出す枠」** に入ります
2. 確かめて **TAKE**（または **Spaceキー**）→ ビジョン（PROGRAM）に出ます（CUT／FADE・時間を選べます）
3. 「操作したらすぐ本線へ」にチェックすると、プレビューを使わずに操作がそのままビジョンに出ます
4. **BLACK** でビジョンを黒にします（もう一度押すと戻ります）

### レイアウト

| レイアウト | 内容 |
|---|---|
| 32:9 一枚 | 3840×1080 の一枚絵。**16:9 の素材を入れると上下を切り取って 32:9 にします** |
| 16:9 左右2枚 | 左と右に、別々のスライド・カメラ・選手紹介を出します |
| 16:9 1枚（位置指定） | 16:9 を **左／中央／右**、またはスライダーで好きな位置に置きます。後ろの「背景」（32:9）も別に選べます |

### トリミング（切り取る位置）

- 「上下」スライダー・数字・[上][中][下] で、切り取る位置を自由に決められます（「左右」「拡大」も同じ）
- **プレビューの枠をドラッグ**しても動かせます。**マウスホイールで拡大・縮小**します
- 「全体を出す」にすると、切り取らずに素材の全体を出します（すき間は黒）
- 「本線にもすぐ反映」にチェックすると、ビジョンに出ている同じ素材の位置を、出したまま調整できます

### スライドの登録

- 画像（PNG・JPEG・WEBP・GIF・SVG）・動画（MP4・WEBM・M4V、500MBまで）を、素材タブの枠に**ドロップ**すると `slides/` フォルダに保存されます
- 「分類」に名前を入れると、`slides/分類/` に分けて保存されます（例：開会式・選手紹介）
- `slides/` フォルダに直接ファイルを入れたときは「⟳ 読み直す」を押します
- 32:9 のスライドは、押すと自動で「32:9 一枚」になります
- 動画は音なしで流します（音は音楽バーで出します）

### カメラ（キャプチャーボード）

- 設定タブの「カメラの一覧を出す」→ カメラ1・カメラ2 にキャプチャーボードを選びます
- 素材タブの「📹 カメラ1／カメラ2」で枠に入れます（トリミングもできます）
- 左右2画面で出しているときは、**映っている側の画面だけがカメラを開きます**。左右にまたがって出したときは、両方の画面が同じカメラを開きます。
  キャプチャーボードによっては同時に開けない機種があるため、本番前に確かめてください
- **I-O DATA などのUSBキャプチャーボード**は、管理画面のブラウザとビジョン出力のブラウザから同時に開けないことがあります。
  そのため、管理画面のプレビューには**初めはカメラを映さない設定**にしています（設定タブで変えられます）

## 3. 選手紹介（打席・選手交代・HR競争）

### 名簿CSV（Excelで「CSV」保存したものをそのまま読めます。UTF-8／Shift_JIS どちらでも可）

| 列名 | 例 | メモ |
|---|---|---|
| チーム | HOME / AWAY | 無いときは、選手タブで選んでいるチームとして読み込みます |
| 打順 | 1〜9 | スタメン表示・打席表示に使います |
| 背番号 | 25 | 顔写真・選手スライド・登場曲を探すときの名前になります |
| ポジション | 一 / 投 / 遊 … | 1文字の表記は、ビジョンでは「一塁手」などと表示します |
| 名前・ふりがな | 高橋 四郎 / たかはし しろう | |
| 打率・本塁打・打点・防御率 | .301 / 15 / 45 / 2.15 | 空欄は表示しません |
| コメント | | 「コメントを出す」をオンにしたとき表示します |
| 登場曲 | 登場曲/HOME/25.mp3 | music/ からの場所。空なら下の場所を自動で探します |
| スライド | HOME/25.png | players/ からの場所。空なら下の場所を自動で探します |

`roster_sample.csv` が見本です（野球テロップシステムのCSVの列名もそのまま読めます）。

### ファイルを置く場所（「写真フォルダ名」は設定タブのチームの欄。空なら表示名 → HOME/AWAY の順で探します）

| もの | 場所 |
|---|---|
| 顔写真 | `photos/写真フォルダ名/player/背番号.jpg`（png も可） |
| 作った選手紹介スライド | `players/写真フォルダ名/背番号.png`（16:9 の png・jpg） |
| 登場曲 | `music/登場曲/写真フォルダ名/背番号.mp3` |

### 使い方
- 選手を選んで **[打席] [代打] [代走] [守備交代] [投手交代] [HR競争]** を押すと、「出す枠」に入ります（「すぐTAKE」がオンならそのままビジョンへ）
- **作った選手スライドがあれば、それを出します**（無ければ自動で作る紹介カード）
  - 選手スライドは16:9なので、レイアウトが「32:9 一枚」のときは自動で「16:9 1枚（位置指定）」に切り替えます（上下が切れないように）。
    位置（左・中央・右）と背景は、前に決めたものをそのまま使います。左右2枚のときは、選んでいる側に入ります
- 交代のときは「交代で退く選手」を選ぶと、OUT の表示も出ます
- 「登場曲を鳴らす」がオンなら、その選手の登場曲を音楽バーで鳴らします（前の曲はフェードアウト）
- **HR競争**：「＋1本」「アウト」を押すと、ビジョンに出したまま数字だけ変わります
- **スタメン**：打順の入った選手を一覧で出します
- 選手の行をダブルクリックすると「打席」と同じ動きをします

## 4. 式次第（開会式・閉会式など）

1. プレビューに画面を組む →「＋ いまのプレビューを追加」で、キューとして登録します
2. キューを選ぶと、**音楽**（曲を鳴らす／止める）と**メモ**（アナウンス原稿・きっかけなど）を決められます
3. 本番は **「▶ 次へ（NEXT）」** で順番に出します。出すと、次のキューが自動でプレビューに入ります
4. 「GO」で、そのキューをその場で出せます
5. 「ファイルに書き出す／読み込む」で、式次第を保存したり別のPCへ移したりできます

## 6. Stream Deck などから操作する場合

```
http://localhost:3007/api/control?action=操作名&val=値
```

| 操作名 | 例 | 内容 |
|---|---|---|
| take | `action=take` | プレビューをビジョンへ（管理画面を開いておく） |
| next / prev | `action=next` | 式次第の次へ／前へ |
| cue | `action=cue&val=3` | 式次第の3番目を出す |
| black | `action=black` | BLACK（val=on / off、省略で切り替え） |
| cut / fade | `action=fade` | 切り替え方 |
| derby | `action=derby&val=1` | HR競争 +1（-1 / reset） |
| derbyOut | `action=derbyOut&val=1` | HR競争のアウト +1（-1） |
| musicPlay | `action=musicPlay&val=01_入場曲.mp3` | 曲を鳴らす（music/ からの場所。管理画面を開いておく） |
| musicStop | `action=musicStop` | 音楽を止める |

## 7. 注意

- **インターネットなしで動きます。** 書体（Oswald・Noto Sans JP）は `fonts/` に入っています（SIL Open Font License 1.1）。
- 顔写真（`photos/`）・選手スライド（`players/`）・曲（`music/`）・スライド（`slides/`）・保存データ（`data/`）は、Gitの管理から外しています（実在の選手の写真・著作物のため）。別のPCで使うときは、フォルダごとコピーしてください。
- 表示画面で問題が起きたとき（カメラが開けない・画像が読めない等）は、ビジョンには何も出さず、管理画面の上部に赤い文字で知らせます。
- 左右2画面で動画を左右にまたいで流すと、左右でわずかにずれることがあります。またぐ動画が多いときは、3840×1080 の1画面（Mosaic等）で出す方法がおすすめです。
