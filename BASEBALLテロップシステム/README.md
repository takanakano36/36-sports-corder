# 野球・ソフトボール中継用スポーツコーダー 取扱説明書

本アプリケーションは、野球やソフトボールのライブ配信でスコア、イニング、BSO、ランナー状況、選手紹介テロップ、そして球場のバックスクリーンからキャプチャした「球速」「球数」をOBS等の配信ソフトに合成できる、スタンドアロン型のスポーツコーダーシステムです。

サーバーやデータベース等の環境構築は一切不要で、HTMLファイルをブラウザで開くだけで動作します。

## ⚾ BSOカウント＆ランナー操作

* **ボール・ストライク・アウト**:
  * ボール/ストライク/アウトのランプをクリックすると、カウントが+1されます（マニュアルでランプを直接クリックして点消灯させることも可能です）。
  * 4ボールでボールカウント自動リセット、3ストライクで自動的に1アウト加算、3アウトで自動的にチェンジ（イニング半切り替え、BSOクリア、ランナークリア）が実行されます。
  * 「打者交代 (BSクリ)」でボール・ストライクのみクリアできます。
* **ランナー表示**:
  * ダイヤモンドの一塁・二塁・三塁をクリックすることで、ランナーのオン/オフ（ゴールドに点灯）を切り替えられます。「ランナークリア」で全リセットも可能です。

## 📊 選手一覧データ連携 ＆ ワンショットテロップ

### 1. 選手データシート (Excel / CSV) のフォーマット仕様
CSV または Excel ファイルを作成する際は、以下の順番で列を設定してください。

| 列位置 | 列名 | 記載内容の例 | 備考 |
|:---|:---|:---|:---|
| **A列 (1列目)** | 背番号 | `1`, `18`, `51` | 半角数字で入力してください。 |
| **B列 (2列目)** | ポジション | `投`, `捕`, `一`, `二`, `三`, `遊`, `左`, `中`, `右`, `指` | リスト上でも変更可能です。 |
| **C列 (3列目)** | 選手名 | `米倉 羽希`, `佐藤 大雅` | フルネームなど日本語で入力します。 |
| **D列 (4列目)** | 学年/所属 | `3年`, `2年`, `社会人1年` | メモ欄として画面右端に表示されます。 |
| **E列 (5列目)** | 紹介コメント | `エースピッチャー。最速145km/hの直球が武器。` | 紹介テロップに1行で表示される説明文です。 |
| **F列 (6列目)** | 打率 | `.285`, `.000` | 打者紹介時に使用されます。 |
| **G列 (7列目)** | 本塁打 | `2`, `0` | 打者紹介時に使用されます。 |
| **H列 (8列目)** | 打点 | `15`, `0` | 打者紹介時に使用されます。 |
| **I列 (9列目)** | 防御率 | `2.45`, `3.15` | 投手紹介時に使用されます。 |

* **投球数 (J列・10列目) について**: 新規ロード時や別の試合（別データの読み込み時）には自動的に `0` (1球目からスタート) にクリアされます。そのため、データシート内に球数をあらかじめ記入しておく必要はありません。
* **文字コードについて**: CSVはUTF-8 / Shift-JIS(Excelの標準保存形式)のどちらでも自動判別して読み込みます。読み込み後に文字化けが発生した場合は、別の文字コードで保存し直して再読み込みしてください。

### 2. 試合中の選手変更 (スタメン・控え・代打・代走・投手交代) への対応
野球では頻繁に選手変更が発生するため、操作画面からその場で直感的にポジションやオーダーを変更できる機能を搭載しています。
* **スタメンと控えの管理**: ロードされた選手データのうち、先頭9名が自動的に「スタメン（1〜9番）」として、それ以降が「控え」として登録されます。スタメン選手はテーブル上で左端に青太枠がついてハイライトされます。
* **インライン打順変更**: 「打順」のプルダウンから番号（1〜9番 / 控え）を変更すると、即座にスタメン打順順にソートされ、オーダー表が再整理されます。
* **インライン守備位置変更**: 「守備」のプルダウンから守備位置をいつでも変更できます。
* **クイック交代ボタン**:
  * **「打者」ボタン**: クリックすると、その選手が「現在打者」に設定され、名前と背番号がダッシュボードに転送されます。同時に、投手登録の選手であっても、自動的に **打者用成績（打率・本塁打・打点）** でワンショットテロップを配信画面に即座に表示させます。
  * **「投手」ボタン**: クリックすると、その選手が「現在投手」に設定されます。過去のその投手の本日累積球数が自動ロードされ、自動的に **投手用成績（防御率・当日累積球数）** でワンショットテロップを配信画面に表示させます。

### 3. 当日球数の累積管理
* 投手の球数は試合当日にダッシュボード上で個別に累積記録されます。
* 投手交代（中継ぎ）を行って別の投手が投げたあと、再び元の投手に戻した際も、それまでに投げていたその投手の「当日の累積球数」が自動的にロード・再同期されます。

### 4. 選手データの読み込み
* **ローカルCSV/Excel読込**:
  * 各チームの「選手データ読込」から CSV (`.csv`) や Excel (`.xlsx`) ファイルを読み込めます。
  * **スプレッドシート連携**: ウェブに公開（カンマ区切り値 .csv）したURLを入力して一括読み込みすることも可能です。
* **CORS制限対応デモボタン**:
  * ローカルファイル環境でのチェック用として、「**デモ選手(HOME)**」「**デモ選手(AWAY)**」ボタンを用意しています。
  * これらをクリックすると、JS内に内蔵された野球成績付きのデモデータが即座に読み込まれ、ワンショットチェックが行えます。

### 5. ワンショットテロップの表示
* 選手リストの「**表示**」ボタンを押すと、配信画面下部にサッカーテロップを踏襲した美しい選手カードテロップが表示されます。
* **ポジション・打者/投手の自動スタッツ切り替え**:
  * ポジションに「投」が含まれる選手の場合、テロップ内のスタッツエリアは自動的に **投手成績（防御率・投球数）** に切り替わります。また、ダッシュボードの「現在投手」欄に名前と背番号、現在の球数が自動で同期されます。
  * 野手の場合、自動的に **打者成績（打率・本塁打・打点）** に切り替わり、ダッシュボードの「現在打者」欄に同期されます。
* **デザインの美しさとガイドライン遵守**:
  * **サッカー調のプレミアムデザイン**: 白〜ライトグレーの立体的なメタリックグラデーション背景に、下部8pxの黒帯を配した美しさです。
  * **フォントサイズ・ベースラインの統一**: 背番号と学年のフォントサイズを `44px` に統一。さらに、氏名（`42px`）と学年（`44px`）の文字の下端（ベースライン）が完璧に揃うように配置されています。
  * **Auto-scaling（はみ出し防止）**: 一言コメント（最大360px）や氏名が長い場合、枠からはみ出さないようフォントサイズが自動縮小処理されます。

## 🎥 バックスクリーンカメラキャプチャ＆クロップ同期システム

球場のバックスクリーンに表示される「球速計」「投球数」の映像をカメラで撮影し、オーバーレイに自動切り抜き合成する画期的な機能です。

1. **デバイスの選択**: 「カメラデバイスを選択」から撮影しているカメラを選択し、「**カメラ開始**」を押します。
2. **クロップ（切り抜き）エリアの調整**:
  * ダッシュボードのプレビュー上に青枠（球速）と黄枠（球数）が表示されます。
  * スライダーで、カメラ映像内の「球速計の数値部分」と「投球数の数値部分」をそれぞれ綺麗に囲うように `X`, `Y`, `幅`, `高` を調整します。
3. **自動反映**:
  * 切り抜かれた映像はリアルタイムで自動的に縮小・圧縮され、超低遅延で配信画面（オーバーレイ）の「小得点」の右横（SPEED / PITCHES）に合成表示されます。
  * カメラ映像が無い、またはカメラオフのときは、ダッシュボード上の「投球数コントロール（投球 +1）」に入力されている数値がフォールバックテキストとして表示されます。

## 🎥 OBS Studio への設定手順（配信ソフト）

1. OBSの「**ソース**」パネルで「**+**」＞「**ブラウザ**」を追加します。
2. 「**ローカルファイル**」にチェックを入れ、本フォルダ内の `baseball_overlay.html` を選択します。
3. **幅**: `1920`、**高さ**: `1080` に設定します。
4. ダッシュボード側で「**透過 (本番用)**」を選択すると、背景が完全に抜け、スコアボードや選手テロップだけが中継映像の上に重なります。

## 📺 セーフマージン（90%）について
本オーバーレイは、テレビ中継や配信での文字切れを防ぐため、1920x1080画面の「90%セーフティエリア（横1728px、縦972px）」内に主要グラフィックが収まるように設計されています。
* 左上の小得点ボードは、画面端からセーフマージンを考慮し `left: 96px; top: 54px;` を確保して配置されています。
* 下部の選手テロップおよび大得点板は `bottom: 80px;` の余白を空けています。
