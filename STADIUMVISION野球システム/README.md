# スタジアムビジョン野球システム（32:9 ／ フルHD 2画面）

野球場の大型ビジョン（3840×1080 ＝ フルHDを左右に2面）に、スライド・カメラ映像・選手紹介を出すシステムです。
アメフト用の「STADIUMVISION得点板システム」をもとに作っています。**音楽バー・HDMI出力・ショートカットの使い方は同じ**です。
得点板の機能はありません。

---

## 0. かんたん手順（まずはここだけ）

### はじめてのPCで使うとき（1回だけ）
1. この `STADIUMVISION野球システム` フォルダを、PCの好きな場所にまるごとコピーします。
2. PCに **Node.js** が入っていなければ、https://nodejs.org/ja から「LTS」版を入れます。
3. フォルダの中の **「デスクトップにショートカットを作る.bat」** をダブルクリックします。
   → デスクトップに **「野球ビジョン 管理画面」「野球ビジョン HDMI出力」** の2つのアイコンができます。

> Macの場合は、名前に「（Mac）」が付いたファイルを使います（手順は得点板システムのREADMEの「6. Macで使う場合」と同じです）。

### 本番のたびに
| やりたいこと | デスクトップのアイコン |
|---|---|
| 画面を操作する | **「野球ビジョン 管理画面」** をダブルクリック → 管理画面が開きます |
| ビジョンへHDMIで直接出す | **「野球ビジョン HDMI出力」** をダブルクリック → ビジョンの画面に全画面で出ます |
| OBSに取り込む | 管理画面右上の **「⠿ OBSへドラッグ」** をOBSへドラッグ（最初の1回だけ） |

- 黒い画面（サーバー）は、本番が終わるまで閉じないでください。
- 台本・名簿・カメラの設定などは自動で保存されます（`data/state.json`）。PCが落ちても、アイコンから起動し直せば続きから再開できます。
- アメフトの得点板（3006番）と、この野球ビジョン（3007番）は、同じPCで同時に動かせます。

## 1. 映像の出し方

### A. PCのHDMIからビジョンへ直接（ケーブル1本）

1. PCのHDMI端子とビジョン（またはビジョンのコントローラー）をつなぎます。
2. Windows の「設定」→「ディスプレイ」で、
   - 表示方法を **「表示画面を拡張する」** にします。
   - ビジョン側の画面の解像度を **3840×1080** にします。
     一覧に無いときは、グラフィックの設定（NVIDIA コントロールパネル・Intel グラフィックス・AMD Software）の **「カスタム解像度」** で 3840×1080 を作ります。
3. デスクトップの **「野球ビジョン HDMI出力」** をダブルクリックします。ビジョンの画面に全体（3840×1080）を全画面で出します。
   - 画面が32:9になっていないときは、注意と直し方が表示されます（そのままだと上下に黒い余白が付いて小さく出ます）。

> 「野球ビジョン HDMI出力」は、つながっている画面の数で出し方を決めます。
> 1台 → 全体を出す ／ 2台 → 左の画面に左半分・右の画面に右半分（HDMI 2本でつなぐ現場用）／ 3台以上 → 番号で選ぶ

### A-2. HDMI→SDIコンバーター経由（SDI 1本・ビジョンに映るのは1920×1080の中の帯）

スタジアムのスイッチャーへ **SDI 1本** で入れ、スケーラーが **「横100%・上下トリミング」** でLED（例 488×160）に映す現場用です。
SDIは 1920×1080 までなので、3840×1080（32:9）はそのままでは送れません。この形で出すときは、**「32:9」から「SDI 1本」に切り替えて**ください。

1. 管理画面の **⚙（設定）→「出力の形」** で **「SDI 1本（1920×1080 の帯）」** を選びます。
2. 「LEDの大きさ」に **488 × 160** を入れて **「ここから帯を計算」** を押します。
   → 1920×630 の帯（上端 y=225、上下の中央）になります（1920×160÷488 ≒ 630）。
3. ⚙の **「▦ テスト画面を本線に出す」** で、**緑の枠がビジョンの四辺にぴったり合う**ように「帯の上端」「帯の高さ」を直します。
4. レイヤーの置き場所は **左半分・右半分（1枚 960×630）・全面・中央16:9** から選べます（2-2）。**「⇄ 左右入れ替え」**（Stream Deck・`action=swap`）で、PREVIEW のシーンの左右を入れ替えられます。

PC・コンバーター（IMAGENICS CRO-H2SC）の設定：

| 場所 | 設定 |
|---|---|
| Windows のディスプレイ | 「表示画面を拡張する」、解像度 **1920×1080**、拡大縮小 100% |
| CRO-H2SC の EDID | **0（SDI OUT）** か **5（1920×1080）**（1 = 640×480 だと左右に黒みが出ます） |
| CRO-H2SC の OUT SDI | スイッチャーに合わせる（多くは **0 = 1080i 59.94**） |

- 「野球ビジョン HDMI出力」は、SDI 1本のときは**左右に分けず**、1つの画面に 1920×1080 で出します（ビジョン用の画面が2台以上あるときは番号で選びます）。
- 32:9 のときにビジョン用の画面が2台見つかると左右に分けて出すため、ノートPCの画面＋HDMI＋もう1台などの状態だと「左右が別々の画面に出る」ことがあります。

### B. OBSに取り込む場合

アドレスを覚える必要はありません。管理画面の右上「**OBSに入れる**」から入れます（得点板システムと同じ。最初の1回だけ）。

1. OBSの「設定」→「映像」で、**基本（キャンバス）解像度と出力解像度を 3840×1080** にします。
2. 管理画面の「**⠿ OBSへドラッグ**」をOBSのプレビューの上へドラッグ＆ドロップします（幅3840・高さ1080のブラウザソースになります）。
   - または「**アドレスをコピー**」を押し、OBSで「ソース」→「＋」→「ブラウザ」を追加してURL欄に貼り付けます（幅 `3840`・高さ `1080`、「ローカルファイル」のチェックは外す）。
3. OBSの出力（プロジェクター出力など）をビジョンへ送ります。

**OBSでカメラ（キャプチャーボード）を使うとき**（昨年と同じやり方）

「OBSに入れる」で入れた表示画面は、**カメラ1・カメラ2を入れた枠だけが透明**になります（カメラは開きません）。
OBSでキャプチャーボードを **ブラウザソースの下** に敷くと、その枠からカメラが見えます。

1. OBSの「ソース」→「＋」→「映像キャプチャデバイス」で、I-O DATAのキャプチャーボードを追加します。
2. ソースの並びで、**映像キャプチャデバイスを、ブラウザソース（野球ビジョン）より下** にします。
3. 映像キャプチャデバイスの位置・大きさを、カメラを出す枠に合わせます（ソースを右クリック →「変換」→「変換の編集」）。

| 管理画面でカメラを入れる枠 | 映像キャプチャデバイスの位置 | 大きさ |
|---|---|---|
| 16:9 左右2枚 の「左」 | 0, 0 | 1920 × 1080 |
| 16:9 左右2枚 の「右」 | 1920, 0 | 1920 × 1080 |
| 16:9 1枚（中央） | 960, 0 | 1920 × 1080 |
| 32:9 一枚（上下を切り取る） | 0, -540 | 3840 × 2160 |
| **守山（SDI 1本・帯 y=197／高さ686）** 右面のカメラ（全面・既定「切り取って全面」） | 960, 197 | 境界ボックス 960 × 686（「境界ボックスの種類」は **内側に合わせて切り抜き（Scale to inner bounds）**） |
| 守山 右面のカメラ（「16:9のまま」。上下は黒） | 960, 270 | 960 × 540 |
| 守山 左面にカメラを入れる場合（全面） | 0, 197 | 境界ボックス 960 × 686（内側に合わせて切り抜き） |
| 守山 左面にカメラを入れる場合（16:9のまま） | 0, 270 | 960 × 540 |

- 守山の右面カメラの収め方は、PREVIEW のトリミングの「枠いっぱい／全体を出す」（カメラの枠）か、台本のキューの右面（カメラ → 「切り取って全面／16:9のまま」）で選びます。「16:9のまま」のときは、OBSの透明な穴も 960×540 になり、上下は黒（不透明）になります。

- カメラを出さないときは、ブラウザソースがカメラを隠すので、映像キャプチャデバイスは出したままで大丈夫です。
- カメラの切り取り位置・拡大は、管理画面ではなく OBS の「変換」で決めます（管理画面のトリミングはカメラには効きません）。
- 枠の位置ごとに使い分けるときは、位置を変えた映像キャプチャデバイスを複数作り、目のマークで出し分けるか、OBSのシーンを分けます。
- BLACK を押すと、カメラも含めて黒くなります。
- ブラウザの中でカメラを開きたいとき（OBSを `--enable-media-stream` を付けて起動した場合など）は、OBSのURLから `camera=obs&` を消します。

### 共通
- 左右を取り違えていないかは、⚙の **「▦ テスト画面を本線に出す」** で確かめられます（左に「L」、右に「R」と出ます）。
- 「境目の線」にチェックを入れると、2画面の境目に赤い線を出せます（設置・調整用）。
- 表示を終わるときは、その画面をクリックして **Alt＋F4** を押します。
- カメラ（キャプチャーボード）の許可は、出力用の画面では自動で許可します（キオスクモードでは許可のボタンを押せないため）。

## 2. 画面の作り方と出し方（OBS型：シーン＋レイヤー）

管理画面は、OBSと同じ **「シーン」と「レイヤー」** で画面を作ります（1920×1080・スクロールなし・タブなし）。

```
┌ 上段   タイトル ｜ 左フタ・全面フタ・BLACK・⚙（設定）
├ 2段目  音楽バー（曲ボタン・STOP・小さく・くり返し・音量・曲のフォルダ）
└ 本体   シーン（左）｜ PREVIEW ／ TAKE ／ PROGRAM（中央）｜ レイヤー（右）
```

- **シーン**（左）：作った画面の一覧です。サムネイルは帯（14:5）の形。**クリック＝PREVIEWに入れて編集対象にする／ダブルクリック＝すぐ本線へ（TAKE）**。
  PREVIEW のシーンは緑の枠、本線に出ているシーンは赤の枠です。グループの見出し（台本のシート名・「いつでも」）で分かれています。
  下の **［＋］**（新しいシーン）・**［複製］**・**［－］**（消す）・**［台本から作る］**。ドラッグで並べ替え（別のグループの上に落とすと、そのグループに移ります）。
  名前は **右クリック →「名前を変える」**（または **F2**）。「グループを変える」「複製」「消す」も右クリックのメニューにあります。
- **PREVIEW**（中央の上）／**PROGRAM**（中央の下、いま本線に出ている画面）／その間の **TAKE の段**（**CUT**・**FADE（秒数も直せます）**・**TAKE**・**次のシーン ▼**＝いま出しているシーンの次を PREVIEW に入れる）。
- **レイヤー**（右）：選んでいるシーンの重なりです（上が手前）。

### 2-1. シーンを作る（3クリックほど）
1. **［＋］** で空のシーンを作る
2. **「🖼 画像」** → フォルダのタブ（全面／ロゴ／進行／入場／選手…）から画像を1クリックで選ぶ → **左半分**に入ります
3. **「📹 カメラ」** → **右半分**に入ります（空いている半分に自動で置きます）

これで「左スライド＋右カメラ」の画面ができあがりです。直した内容は**すぐそのシーンに保存**されます（OBSと同じ）。

### 2-2. レイヤー
- **PREVIEW の枠**：選んでいるレイヤーに黄色の枠が出ます。**ドラッグで移動、角で大きさ**。**左半分・右半分・全面・中央16:9 に吸着**します（吸着したときは名前が出ます）。
- **置き場所ボタン**：左半分／右半分／全面／中央 16:9（選んでいるレイヤーを、その位置・大きさにします）。
- **👁** で表示／非表示、**ドラッグで重なり順**を変えます。選ぶと黄色の枠。**Delete キーで選んだレイヤーを削除**（確認が出ます）。
- **レイヤーを足す**：画像（slides から選ぶ。フォルダのタブ付きのグリッド）／カメラ／色／文字／ロゴ（フタの画像）／動画。
  14:5（全面）の画像を選ぶと、自動で全面に入ります。
- **細かい設定**（レイヤーの下の小さな欄）：カメラ1／カメラ2・差し替え・枠いっぱい／全体を出す・不透明度・色・文字・削除。
  文字のレイヤーに `{HR}` と書くと、ホームラン競争のカウンター（⚙の設定）の数字に置き換わります。
- **このシーンの音**（BGMを使う設定のときだけ）：変えない／♪ 曲を選ぶ（くり返し）／フェード／停止／小さく／戻す。**TAKEで本線に出たときに**、音楽バーの再生（音量・フェード・出力先）で動きます。曲は音楽バーのもの（「曲のフォルダ」で選んだ別フォルダの曲も使えます）。

### 2-2b. BGMを使う・使わない（⚙「BGM（音楽）をこのシステムで鳴らす」）
- **既定は OFF**（iPad などで別にポン出しし、音量もミキサーで手で操作する運用向け）。OFF のときは、音楽バー・「このシーンの音」・♪や「小」のバッジ・BGMのキーが出ず、シーンを出しても曲の再生・フェード・停止・小さくは一切しません。`/api/control` の `musicPlay` `musicStop` `musicFade` `musicDuck` は、何もせず 200（`ignored:true`）で返します。
- シーンに付けた音の設定は消さずに残るので、ON に戻せば効きます。台本から作るときの BGM 提案は付きますが、OFF では「曲が見つかりません」の ⚠ は出しません。
- 15キーの Stream Deck は、OFF のとき中段3番目・下段（BGMの段）が **グループ（シート）へジャンプ** のキーになります。

| | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 上段 | NEXT ▶ | ◀ PREV | 選ぶ ↑ | 選ぶ ↓ | TAKE |
| 中段 | 左フタ | 全面フタ | ⇄ 左右入れ替え | カメラのフタ | BLACK |
| 下段 | グループ1 | グループ2 | グループ3 | グループ4 | グループ5 |

### 2-2c. カメラのフタ（カメラ待ち）
- 本番の最初は、カメラの映像がまだ来ていません。そこで **カメラのレイヤーのすぐ上に、フタの画像（`slides/ロゴ/L_960x686_horiz_black.png`。⚙で別の画像にもできます）を自動で重ねます**。すべてのシーン（台本から作ったシーン・「いつでも」・新しく足したカメラ・以前の保存データ）に付き、カメラを動かすとフタも付いてきます。レイヤー一覧には「🔒 カメラのフタ（上のボタンで切替）」と出ます。
- **本番の流れ：開始時はフタ ON（上段の「カメラ待ち（フタ ON）」）→ カメラがレディになったら、その「カメラのフタ」ボタンを1回押して外す。** 本線（PROGRAM）も含め、全シーンのフタが**すぐ**消えてカメラが見えます（TAKE は要りません）。もう一度押すと、すぐフタが付きます。
- 1つのシーンだけフタを外したいときは、そのフタのレイヤーを選んで削除します（そのシーンには付け直しません）。
- OBS取り込み（`camera=obs`）でも、ON のときは穴の上にフタの画像が描かれてカメラを隠し、OFF のときはカメラが見えます。
- Stream Deck：「カメラのフタ」キー（15キーでは中段4番目。下の表を見てください。⇄ 左右入れ替えは、BGMを使う設定のときは優先順位の後ろに回ります）／HTTP：`action=lid&val=on|off`（省略で切り替え）。

### 2-3. 出し方
- **TAKE**（Space／Enter／大きなボタン）：PREVIEW のシーンを本線に出します（CUT／FADE）。本線には**シーンのコピー**が出るので、そのあとシーンを直しても、TAKE するまで本線は変わりません（⚙の「本線に出ているシーンを直したら、すぐ本線にも反映する」で変えられます）。
- 台本の流れのシーン（「いつでも」以外）を TAKE すると、**自動で次のシーンが PREVIEW に入ります**。
- **BLACK**：ビジョンを黒にします（もう一度で戻る）。**左フタ・全面フタ**：ロゴを本線に出します（もう一度で直前の画面に戻る）。BLACK とは別物です。
- **キー**：↑↓＝シーンを選ぶ（PREVIEW）／Space・Enter＝TAKE／→＝次のシーンを出す／←＝前のシーンを出し直す（音は鳴らし直しません）／**B**＝BLACK／**L**＝左フタ／F2＝名前／Delete＝レイヤー削除。入力中・ダイアログを開いている間は効きません。
- 最初から **「いつでも」** のシーンが5つあります：全面 ロゴ／全面 まもなく開会式（`slides/全面/` に画像があれば使います）／カメラ全面／左ロゴ＋右カメラ／黒。

### 2-4. スライドの登録・カメラ・設定（⚙）
- 画像（PNG・JPEG・WEBP・GIF・SVG）・動画（MP4・WEBM・M4V、500MBまで）は `slides/` フォルダに入れます（フォルダ分けは自由。例：`slides/進行/…`）。
  画像を選ぶ画面の **「ファイルを足す」** でも登録でき、`slides/` に直接入れたときは **「⟳ 読み直す」**。`design_tools` の「ビジョンにセット」で `slides` が入れ替わったときは、管理画面が自動で読み直します。動画は音なしで流します（音は音楽バーで出します）。
- **⚙（設定）** のダイアログに、出力の形（32:9／SDI 1本／守山）・カメラの選択・フタの画像・Stream Deck・OBSへのドラッグ・確認用の表示・テスト画面・境目の線・HR競争カウンターがあります。
  **▦ テスト画面**：本線にテスト画面を出します（緑の枠がビジョンの四辺に合うか確かめます。もう一度押すと元の画面に戻ります）。
- **カメラ**：⚙の「カメラの一覧を出す」→ カメラ1・カメラ2 にキャプチャーボードを選びます。左右2画面で出しているときは、**映っている側の画面だけがカメラを開きます**。
  USBキャプチャーボードは、管理画面とビジョン出力のブラウザから同時に開けないことがあるため、管理画面のプレビューには**初めはカメラを映さない設定**です（⚙で変えられます。PREVIEWには「📹 遊撃カメラ」とだけ出ます）。
- **OBSに取り込むとき**（`camera=obs`）は、カメラのレイヤーが**透明な穴**になり、その下のレイヤー（背景の色など）も穴の形にくり抜かれます。OBSの「映像キャプチャデバイス」を下に敷くと、穴から見えます。

## 3. 選手スライド・HR競争

- 作った選手スライド（`design_tools` で作る 16:9 の画像）は、**ふつうの画像として** `slides/選手/チーム名/…` などに置き、画像レイヤーで使います（「当日に選ぶ」シーンは 4-2 を見てください）。
- **HR競争カウンター**：⚙の設定で「＋1本」「アウト」を押します。文字のレイヤーに `{HR}` と書くと、ビジョンに出したまま数字だけ変わります。
- 旧版の選手紹介カード・スタメン表・名簿CSVの画面はなくなりました（保存データの名簿は残っています）。

## 4. 守山の2画面・台本から作る・Stream Deck

### 4-1. 守山2画面
- 新しく始めたときの既定は **SDI 1本・帯の上端 197・高さ 686（1920×686＝14:5）** です。すでに保存してある設定は書き換えません。⚙の **「守山（197／686）」** で、いつでもこの形にできます。
- 左半分・右半分は 960×686。ふつうは **左にスライド、右に遊撃カメラ（カメラ1）**。帯全体に1枚（全面）も出せます。
- **フタ（ロゴ画面）**：「左フタ」は左面だけロゴ（右は今の画面のまま）、「全面フタ」は帯全体がロゴです。ロゴは `slides/フタ/` の最初の画像（⚙で左フタ用・全面フタ用を選べます。画像が無いときは黒になり、注意が出ます）。

### 4-2. 台本から作る（Excel → シーン）
1. 左下の **［台本から作る］** を押し、台本の Excel（.xlsx）を**ドロップ**（または「ファイルを選ぶ」）します。.csv / .tsv と、貼り付けも使えます。
   上限：ファイル 20MB・シート 30枚・1シート 3000行・1セル 5000文字。壊れたファイルなどは、理由が日本語で出ます。
2. **列の割り当て**の画面で、シートごとに見出しの行と各列の役割（番号・時刻・所要・場面・BGM・ビジョン【左】【右】・話者・セリフ…）を確かめ、**「この内容でシーンを作る」**。ふつうは自動で合います。
3. **キューの付く行（スライド・曲・カメラが変わる行）ごとに、シーンができます**。
   - 名前＝番号＋場面、グループ＝シートの名前（開会式・HRダービー・閉会式…）。
   - レイヤー＝左にスライド（ビジョン【左】の文字を `slides/` のファイルと照合）＋右に遊撃カメラ。全面の画像なら全面。`（継続）` の行は前のスライドのままです。
   - 音＝BGM 列から（`xxx.mp3 ループ再生`／`1回のみ`／`継続`／`フェードアウト`／`無音`／`小さめ`／`フェードアップ`。曲は `music/` の曲と名前で照合）。曲・スライドが見つからないシーンには、⚠ が付きます（マウスを乗せると内容）。
   - **「当日に選ぶ」**（`（背番号）` `NN_` `（優勝チーム）` など当日に決まるもの）は、サムネイルの位置に **「＋選ぶ」**。押すと、そのフォルダの画像だけがサムネイルで並び、1クリックで決まります。
     同じフォルダが続く行（例：打者1の「呼び込み」「競技」「終了」）は、1つのシーンにまとめます（ダイアログのチェックで、1行ずつに変えられます）。
4. **読み直し**：台本を直して、もう一度［台本から作る］を押すと、**番号（O-06 など）が同じシーンのうち、手で直していないものだけ更新**します。レイヤー・音・名前を手で直したシーンはそのまま残り、画面に件数と名前が出ます。台本から無くなった行のシーンは、消さずに残します。
5. シーンは `data/state.json` に保存されます（人名を含むため、Git には入りません）。

**以前の保存データ**（レイアウト＋枠の画面・台本のキュー入り）は、起動したとき自動でシーンに変換されます（キューの付いた行 → 1シーン、本線の画面 → レイヤー）。

### 4-3. 本番の出し方（台本の流れ）
- 台本から作ったシーン（「いつでも」以外）は、**上から順に出していきます**。**→（NEXT）**＝次のシーンをすぐ本線へ、**←（PREV）**＝1つ前を出し直す（音は鳴らし直しません）。**クリック→PREVIEWで確かめる→TAKE** でも出せます。
- 出すと、シーンの「音」（BGMの再生／フェードアウト／停止／小さく／戻す）が動きます。すでに同じ曲が鳴っているときは二重に鳴らしません。
- 途中のシーンを飛ばしたいときは、飛ばし先のシーンをクリックして TAKE します（そこから先は、また → で進みます）。

### 4-4. Stream Deck のつなぎ方とキー配置
- **Chrome か Edge** で管理画面を開き、Stream Deck を USB でつなぎます（Elgato の公式アプリは閉じておきます）。⚙の **「Stream Deck を接続」** を押して機器を選びます。2回目からは自動でつながり、抜き差しにも追従します。
- 機種（Original／Mini／MK.2／XL／+）は自動で見分け、キーに文字と色が出ます（ONのキーは明るく枠が付き、OFFは暗い色）。キーを押すと、画面のボタンと同じ動きをします。
- 押したキーと別のキーが反応するときは「位置ずれ」、上下が逆のときは「上下反転」で合わせます。⚙の「キー配置の見本」でも、押して試せます。
- 注意：実機で確かめているのは MK.2 型（JPEG方式）の想定です。BMP方式の機種（初代・Mini）は、画像の向きを上下反転ボタンなどで合わせてください。

**15キー（5×3）の配置**

| | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 上段 | NEXT ▶（次のシーン名） | ◀ PREV | 選ぶ ↑（PREVIEW） | 選ぶ ↓（PREVIEW） | TAKE（PVW→本線） |
| 中段 | 左フタ | 全面フタ | BGM 小さく⇔戻す | カメラのフタ | BLACK（ONで赤） |
| 下段 | BGM 1 | BGM 2 | BGM 3 | BGM フェードアウト | BGM 即停止 |

- BGM 1〜3 は音楽バーの先頭3曲（鳴っている曲は点灯）。⚙で別の曲に差し替えられます。「⇄ 左右入れ替え」は、PREVIEW のシーンのレイヤーを左右反転します。
- 6キー（Mini）・8キー（+）は、優先順（NEXT, PREV, 左フタ, BLACK, BGMフェード, BGM停止, 全面フタ, TAKE, …）の上から詰めます。
- 32キー（XL）は、左の5列が15キーと同じ並びで、右の3列と最下段に BGM 4〜12・グループ（シートの名前）へジャンプ（8つまで）・「BGM 小さく」が並びます。

## 6. Stream Deck などから操作する場合

```
http://localhost:3007/api/control?action=操作名&val=値
```

| 操作名 | 例 | 内容 |
|---|---|---|
| take | `action=take` | PREVIEW のシーンをビジョンへ（管理画面を開いておく） |
| swap | `action=swap` | PREVIEW のシーンの左と右を入れ替える（管理画面を開いておく） |
| next / prev | `action=next` | 台本の流れの次のシーンを出す／前のシーンを出し直す（PREVはBGMを鳴らし直さない）。音は管理画面が鳴らします |
| cue | `action=cue&val=3` | 台本の流れ（「いつでも」以外）の3番目のシーンを出す |
| futa / futaFull | `action=futa` | 左フタ／全面フタのオン・オフ（もう一度で元の画面） |
| readNext / readPrev | `action=readNext` | PREVIEW を1つ下／上のシーンへ（出さない。管理画面を開いておく） |
| musicFade | `action=musicFade` | 音楽をフェードアウト（管理画面を開いておく） |
| musicDuck | `action=musicDuck&val=on` | BGMを小さく／戻す（val=on / off、省略で切り替え。管理画面を開いておく） |
| lid | `action=lid&val=on` | カメラのフタの付け外し（val=on / off、省略で切り替え。本線にもすぐ反映） |
| black | `action=black` | BLACK（val=on / off、省略で切り替え） |
| cut / fade | `action=fade` | 切り替え方 |
| derby | `action=derby&val=1` | HR競争 +1（-1 / reset） |
| derbyOut | `action=derbyOut&val=1` | HR競争のアウト +1（-1） |
| musicPlay | `action=musicPlay&val=01_入場曲.mp3` | 曲を鳴らす（music/ からの場所。管理画面を開いておく） |
| musicStop | `action=musicStop` | 音楽を止める |

## 7. 注意

- **インターネットなしで動きます。** 書体（Oswald・Noto Sans JP）は `fonts/` に入っています（SIL Open Font License 1.1）。
- 顔写真（`photos/`）・選手スライド（`players/`）・曲（`music/`）・スライド（`slides/`）・保存データ（`data/`）は、Gitの管理から外しています（実在の選手の写真・著作物のため）。別のPCで使うときは、フォルダごとコピーしてください。
- 表示画面で問題が起きたとき（カメラが開けない・画像が読めない等）は、ビジョンには何も出さず、管理画面の上部に赤い文字で知らせます。
- 左右2画面で動画を左右にまたいで流すと、左右でわずかにずれることがあります。またぐ動画が多いときは、3840×1080 の1画面（Mosaic等）で出す方法がおすすめです。
